MJSCalc package repositories

dnf (RHEL, AlmaLinux, Rocky, Fedora)

  • MJSCalc 3.19.2 (el10, 64-bit ARM)
  • MJSCalc 3.19.2 (el10, 64-bit Intel/AMD)

Add the repository once, then MJSCalc updates with the rest of the system:

sudo rpm --import https://msanty573.github.io/MJSCalc-Downloads/RPM-GPG-KEY-mjscalc
sudo curl -o /etc/yum.repos.d/mjscalc.repo https://msanty573.github.io/MJSCalc-Downloads/mjscalc.repo
sudo dnf install mjscalc

apt (Ubuntu 26.04 and newer)

  • MJSCalc 3.19.2 (64-bit Intel/AMD)
  • MJSCalc 3.19.2 (64-bit ARM)

Installing the package also adds this repository, so MJSCalc then updates with the rest of the system:

wget https://github.com/msanty573/MJSCalc-Downloads/releases/download/latest/mjscalc.ubuntu.$(dpkg --print-architecture).deb
sudo apt install ./mjscalc.ubuntu.*.deb
